
# Dice Roller Program

A simple dice roller that generates random dice images.

## Features

- Roll from 1 to 6 dice
- Random result every time
- Displays dice images
- Input validation

## Technologies

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone the repository.
2. Make sure the `images` folder is included.
3. Open `index.html`.
