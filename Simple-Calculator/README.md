
# Simple Calculator

A basic calculator made with HTML, CSS, and JavaScript.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal numbers
- Clear button
- Error handling
- Large number detection

## Technologies

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone the repository.
2. Open `index.html`.

## What I Learned

- DOM manipulation
- JavaScript events
- `eval()`
- Error handling with `try...catch`
- Working with strings and numbers
