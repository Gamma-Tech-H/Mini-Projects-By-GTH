
# Password Generator

A password generator built using JavaScript.

## Features

- Generate random passwords
- Choose uppercase letters
- Choose lowercase letters
- Choose numbers
- Choose symbols
- Select password length

## Technologies

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone the repository.
2. Open `index.html`.
